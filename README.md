# 一碗海风的迁徙 · H5（V3）

《出版与数字出版》结课作品配套 H5：一张关于闽粤桂琼四省的美食地图，6 个文化地域、34 道菜，记录百余年来海内外交融中的舌尖变迁。

- 封面 → 目录 → 地图 → 地域 → 菜品，五级页面
- 手机浏览器打开即为全屏；电脑浏览器打开为居中手机框
- 三段《舌尖上的中国》环境音顺序循环，翻页不中断，右下角可静音
- 34 道菜每道有图片位与家族记忆来稿人署名；20 道附解说音频（其余 14 道暂缺，补齐同名文件即自动出现）

## V3 改了什么（四项）

### 一、修复：地域页菜条「手指或鼠标一放上去，图片就变、位置错乱」

**根因不是图片加载，是两条陈旧的 hover 样式。** 菜条从"纯色按钮"改成"满幅菜品图"之后，这两条旧规则没有一起清掉：

| 旧规则 | 实际后果（无头浏览器实测） |
|---|---|
| `.dishitem:hover{background:var(--card-2);border-color:var(--sun)}` | `background` 是**简写**，会把 `background-size` / `background-position` 一并重置：`cover / 50% 50%` → `auto / 0% 0%`。铺满整条的模糊占位图瞬间退化成左上角一个 20px 小方块，背景色从深蓝 `rgb(14,74,120)` 变成浅蓝 `rgb(79,195,247)` |
| `.dishitem:hover{transform:translateY(-1px);box-shadow:…}` | 整条上移 1px、阴影突变，相邻条目看起来"错位" |

**处理**：删除这两条规则；给菜条加 `-webkit-tap-highlight-color:transparent`，关掉移动端按下时的系统灰色高亮。现在手指/鼠标悬停、按下，图片与位置都不再变化。

### 二、左右平移 → 模拟书页翻页

原来是 `translateX` 整体平移，现在改成 `perspective() + rotateY` 的 3D 翻页：

- **层级翻页**（封面 / 目录）：旧页沿左（或右）边缘向内翻走，翻到 100° 隐去；新页从另一侧 86° 合拢归位，两段各 340ms。
- **菜品页切菜**：菜品内容块以同样方式翻过去，顶栏（返回 / 菜名）与底栏常驻不动，两段各 230ms。
- 点击按钮（开启旅程、返回、目录）仍走原来的 2 秒淡入淡出，与手势动画互不干扰。
- 地图页保留点击与放大，不接管水平手势。

### 三、修复：菜品页下滑返回落到封面

`closeDish()` 改为**明确落回「地域目录」**：

- 先 `go('map')`，再强制地图进入详情态，并 `open()` 到**当前这道菜所属的地域**——即使中途左右滑跨到了别的地域，返回也落在当前菜的地域，不会回错。
- 下滑手势触发时置 `__pullHandled` 消费标志，同一次触摸序列不会被外层手势再判成"翻到封面"。

**操作方式**：菜品正文滚到顶部后继续向下拉（下拉时页面会跟着下移给反馈），或直接点左上「← 返回本地区」。

### 四、封面删去「作者：」前缀

「开启旅程」按钮上方现在只显示六个名字：**许湘俞 颜诗玲 张一丁 赖伟超 秦雨晴 谢雅婷**，字号与下方「4 省份 / 34 道菜」一致（12px），单行。

## 部署到 GitHub Pages

### 情况 A：V2 已经在线上（最省事，推荐）

V3 只改了 `index.html`，图片和音频与 V2 完全相同，**不用重传 8MB**：

1. 打开你的仓库 → 点进根目录的 `index.html`
2. 右上角铅笔图标（Edit）或直接 `Add file → Upload files`
3. 把 V3 文件夹里的 `index.html` 拖进去，覆盖同名文件 → `Commit changes`
4. 等 1–2 分钟，手机打开链接，**强制刷新**（Safari 关掉标签重开，Chrome 下拉刷新或清缓存）看效果

### 情况 B：新建仓库、整包上传（第一次部署，或想彻底重来）

1. **建仓库**：登录 github.com → 右上角 `+` → `New repository`
   - Repository name 建议英文小写加连字符，如 `yifan-haifeng-h5`（会出现在网址里）
   - 选 **Public**（免费账号只有公开仓库能开 Pages）
   - **不要勾 Add a README** → `Create repository`
2. **上传文件**：点 `uploading an existing file`，把**本文件夹里面的内容**（`index.html`、`assets`、`README.md`）一起拖进去——注意拖的是文件夹里面的东西，不是外层文件夹。
   - 一次拖 59 个文件如果卡住，就分两批：先 `index.html` + `README.md` 提交，再拖整个 `assets` 文件夹提交。
   - **`assets` 要整个文件夹拖**，不要只拖里面的三个子文件夹，否则路径会少一层、网页找不到图。
3. **开启 Pages**：`Settings → Pages → Source: Deploy from a branch` → Branch 选 `main`、文件夹选 `/ (root)` → `Save`。首次要等 2–10 分钟。
4. **访问**：`https://<你的用户名>.github.io/<仓库名>/`（尖括号不用写）。手机、电脑都能打开。

## 注意事项

- **中文路径**：`assets/图片` 等中文目录名 GitHub 完全支持，不需要改名。
- **更新内容**：改完本地文件，仓库里 `Add file → Upload files` 覆盖同名文件，1–2 分钟后自动重新部署，不用再动 Pages 设置。
- **底图口径**：地图页脚为「底图：天地图 · 课堂展示」，全文不出现审图号占位字样。
- **验收建议**：用手机 4G 打开一次（模拟同学的真实网络）。重点看：①地域页菜条背景是清晰照片，手指按住不放图片不变、位置不动；②左右滑动时是"书页翻过去"的透视感，不是整块平移；③菜品页下拉能回到**带 9 道菜列表的地域页**，不是封面；④封面按钮上方只有六个名字。
- **缓存**：GitHub Pages 的资源只缓存 10 分钟且不可自定义，改完看不到新效果时，先用无痕窗口或强制刷新确认。
- 本包基于 V2 部署包生成，V3 只改交互与一处文案，文案与图片内容未变。
